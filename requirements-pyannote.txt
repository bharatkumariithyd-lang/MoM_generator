# Optional extras for pyannote.audio speaker diarization (--speakers pyannote)
# ==========================================================================
# pyannote gives more accurate "who spoke when" than the Resemblyzer option
# (--speakers voice), but its pretrained models are GATED on Hugging Face, so
# there is a ONE-TIME setup before it will run:
#
#   1. Create a Hugging Face account (https://huggingface.co/join).
#   2. Accept the user conditions at:
#        https://huggingface.co/pyannote/speaker-diarization-community-1
#   3. Create a token WITH "Read access to contents of all public gated repos
#      you can access": https://huggingface.co/settings/tokens
#   4. Put it in your .env next to the script:   HF_TOKEN=hf_xxx
#
# Install with:  pip install -r requirements-pyannote.txt
#
# Heavy: pulls in torch / torchaudio. Diarization is slow on CPU and fast on a
# GPU, so prefer a short clip when testing locally without a GPU.
#
# We feed pyannote an in-memory waveform loaded with librosa (listed below),
# which avoids pyannote 4.x's torchcodec/FFmpeg audio path that fails on many
# machines. librosa is also part of requirements-voice.txt.

pyannote.audio
librosa
